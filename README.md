## 🔎 **Description**

This repository houses two integrated frontend projects: my professional portfolio and a custom Linktree clone.

Designed to reflect my journey as a Full-stack Developer, the portfolio goes beyond simply listing previous roles—it showcases my technical capabilities, problem-solving mindset, and continuous evolution in software engineering. The Linktree clone complements this by serving as a fast, consolidated hub for my professional presence.

## ✨ **Key Features**

- **Custom i18n Implementation:** Built a bespoke internationalization system from scratch using JavaScript objects to handle dynamic text rendering in both English and Portuguese without relying on heavy external libraries.
- **Component-Driven Architecture:** Clean, modular, and highly reusable components using React and Styled Components.
- **Responsive Design:** Fluid user experience across all mobile and desktop devices.
- **Optimized Build:** Leveraged Vite for lightning-fast development and optimized production bundles.

## 🔨 **Technologies Used**

Both projects share a modern, performant frontend stack:

- **Core:** React.js, TypeScript
- **Build Tool:** Vite
- **Styling:** Styled Components
- **Routing:** React Router DOM (Portfolio)
- **Deployment:** Vercel
